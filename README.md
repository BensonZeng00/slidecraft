# 幻灯匠 / Slidecraft

**先设计，再制作：让 PPT 不止于套模板，更不用开盲盒。**

有了内容，却找不到合适的模板；AI 生成的图片很好看，想改一句话、挪一个位置，却又得重新来过。

幻灯匠让内容决定画面：先根据主题生成完整的信息图，**你看过、确认满意后，再制作可编辑 PPT**。不必等整页做完才发现风格不对。也可以上传喜欢的信息图，直接指定它作为复刻目标。

**两步完成：① 看设计图，确认或修改；② 复刻 PPT，检查后交付。** 单页同样先确认，不自动越过这一步。

不用先挑模板，也不用自己从空白页逐个摆放元素。它增强你已有的 PPT 工具，让个性化构图、插画与后续编辑衔接起来。

## 它能帮你做什么

- **从想法到页面**：输入主题，生成信息图，再制作可编辑 PPT，减少手工排版。
- **让参考图继续可用**：重建已有图片或 SVG，方便改文案、调布局、复用内容。
- **减少整套返工**：多页先讨论大纲和每页内容，你确认后再逐页制作，每页满意再继续。
- **控制重复生成**：提前说明生图数量，默认每页最多 3 次调用，成功即停止，达到上限就暂停。
- **减少机械返工**：优先复用 CLI 做版本、确认记录、文字尺寸和交付检查；生图仍有随机性，不承诺像素级一致。

推荐从单页开始：一条提示词，专注做好一页。

## 安装

将技能 ZIP 上传到支持自定义 Skill 的 AI 助手，或使用平台的技能导入入口。可以把下面这句话发给它：

```text
请安装附件中的 slidecraft 技能，检查生图、可编辑 PPT 制作和渲染能力。
优先复用已有 PPT 技能；缺少时按平台权限尝试安装，无法使用时告诉我原因。
```

技能包内应有 `slidecraft/SKILL.md`。幻灯匠不自带生图模型或 PPT 引擎，实际能力取决于所在平台；安装需要遵循平台权限，不能保证所有应用都能直接运行。

## 使用

选择幻灯匠技能后，直接描述需求。

**有主题，做一页：**

```text
制作一页“人工智能发展简史”，面向非技术听众。
先生成有视觉吸引力的信息图让我确认，确认后再制作可编辑 PPT。
```

**有图片，做还原：**

```text
把这张信息图重建为可编辑 PPT，尽量保留原图布局、文字和风格。
```

**有完整主题，做一套：**

```text
制作一套 6 页的产品方案介绍。
先和我讨论大纲及每页内容，确认后逐页制作，每页完成后让我确认。
```

多页先确认大纲和每页内容，再按“当前页设计图确认 → 制作 PPT → 当前页成品确认”推进。当前页未确认不制作下一页。

## 最后会得到什么

一份可编辑的 `.pptx` 和实际 PPT 预览；文字生图流程还会提供生成的参考图。多页在全部确认后交付一份完整文件。

文字、基础图形和简单关系优先使用原生 PPT 对象。照片、复杂插画和纹理可能保留为独立图片，可移动或替换，但内部细节不能逐项编辑。不会把整页截图贴进 PPT 就宣称“全部可编辑”。
